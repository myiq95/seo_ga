# 서재 · 독서 PWA

txt, docx, pdf, epub, md, html 파일을 읽는 오프라인 독서 앱입니다.

## 파일 구성

```
index.html      화면 구조 (서재 / 읽기 / 메뉴 / 설정)
styles.css      미니멀 서식, 아이보리·나이트 테마
app.js          파서, 서재 저장, 목차 인식, 이어 읽기, 시스템 TTS
sw.js           서비스 워커 (오프라인 동작)
manifest.json   홈 화면 설치 정보
icons/          앱 아이콘
```

## 1. GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다. 이름은 `seoga-reader`처럼 정하시면 돼요. GitHub Pages를 무료로 쓰려면 Public 저장소여야 해요.
2. zip 파일을 풀고, 안에 있는 파일들을 **저장소 최상위에** 올립니다. zip 파일 자체가 아니라 `index.html`, `app.js` 등이 루트에 보여야 해요.
3. 저장소의 **Settings › Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 Save를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/seoga-reader/` 주소로 접속할 수 있어요.

## 2. 아이폰 홈 화면에 설치

1. 아이폰의 **Safari**로 위 주소를 엽니다. (Chrome에서는 홈 화면 설치가 안 돼요.)
2. 처음 한 번은 인터넷에 연결된 상태에서 잠시 기다려 주세요. 이때 앱과 라이브러리가 기기에 저장돼요.
3. 공유 버튼 › **홈 화면에 추가**를 누릅니다.
4. 이후에는 비행기 모드에서도 열리고 읽을 수 있어요.

## 3. 업데이트하는 법

`sw.js` 첫 줄의 `CACHE` 값을 올린 뒤 다시 올립니다. 예: `seoga-reader-v1.0.1`
이렇게 하면 기기가 새 파일을 받아요. 홈 화면 앱은 완전히 닫았다가 다시 열어 주세요.

## 4. 기능 요약

- **서재**: 열어 본 책은 자동으로 남아요. 항목을 눌러 이어 읽고, 휴지통 아이콘으로 개별 삭제할 수 있어요.
- **텍스트 붙여넣기**: 본문을 붙여넣어 바로 서재에 추가할 수 있어요.
- **목차**: 「제N장」, 「N장」, 「Chapter」, 「프롤로그·에필로그」 등을 자동으로 찾아요. 제목이 없으면 본문을 일정 길이로 나눈 임의 목차를 만들어요.
- **책갈피**: 메뉴의 책갈피 아이콘으로 현재 문단에 표시를 남길 수 있어요.
- **설정**: 고딕·명조 글꼴, 글자 크기, 자간, 라이트·아이보리·나이트 테마, 읽어 줄 음성과 속도를 바꿀 수 있어요.
- **음성 읽기**: 기기에 내장된 시스템 음성을 사용해요. 웹 서비스 음성은 쓰지 않아요.
- **메뉴**: 아이콘만 쓰고, 2~3초 동안 조작이 없으면 자동으로 숨어요. 화면을 한 번 누르면 다시 나타나요.

### 음성 준비 (아이폰)

설정 › 손쉬운 사용 › 음성 콘텐츠 › 음성 메뉴에서 한국어 음성을 내려받으면 앱 설정의 음성 목록에 나타나요. iOS 버전에 따라 메뉴 이름이 조금 다를 수 있어요.

## 5. 알아 두실 점

- **데이터 위치**: 책과 읽기 위치는 그 기기 안(IndexedDB)에만 저장돼요. 기기끼리 자동으로 동기화되지 않아요. 중요한 원본 파일은 따로 보관해 주세요.
- **명조 글꼴**: 아이폰에는 기본 명조 글꼴이 없어서 명조를 골라도 고딕처럼 보일 수 있어요. `fonts/NanumMyeongjo.woff2` 파일을 넣으면 명조가 확실히 적용돼요. 나눔명조 웹폰트 파일을 구해 넣어 주세요.
- **스캔본 PDF**: 글자 정보가 없는 스캔 PDF는 지원하지 않아요.
- **목차 규칙 수정**: 목차 인식 규칙은 `app.js`의 `HEAD_RES`와 `isHeadingLike()`에 있어요. 작품 특유의 제목 형식이 있으면 여기에 패턴을 추가하면 돼요.
- **큰 파일**: 수십 MB짜리 파일은 처음 열 때 몇 초 걸릴 수 있어요.
